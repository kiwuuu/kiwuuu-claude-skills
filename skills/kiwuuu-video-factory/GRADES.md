## The proven max-grade formula (46-47/50)

A clip wins all 5 dimensions when ALL of these are true:
1. **Single hero subject** — one icon, one phone, one clock, one orb. Not 4 phones, not a dashboard, not a chat.
2. **Dark void background** — pure black or near-black with subtle particle dust.
3. **Neon green or amber rim lighting** — rim/glow edges, never flat.
4. **No prompt asks for visible text** on any object (no calendars, no chat bubbles, no numbers, no city labels). wan/turbo will gibberish them.
5. **Brand mark applied via ffmpeg overlay** — NOT in the prompt. Always-on `kiwuuu.` electric-lime top-left + `kiwuuu.com` white bottom-right.

## What loses (≤32/50)

- Multiple subjects competing (V08 4channels)
- Any visible UI text in the prompt (V02, V04, V07, V14, V15)
- Generic abstract that doesn't say anything specific (V03 autopilot)

## Batch 5 mandate

All ~10 new prompts must follow the max-grade formula. No screens with text. No chat bubbles. No fake dashboards. Hero object + glow + brand overlay. Council is brainstorming concepts that fit this constraint.
